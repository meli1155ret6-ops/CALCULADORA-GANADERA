Calculadora Ganadera

Aplicación web desarrollada en HTML, CSS y JavaScript que permite calcular la producción y gastos de animales de granja.

🚀 Características

Inicio de sesión y registro de usuarios.

Selección de animales mediante botones grandes (cerdo, vaca, gallina, caballo, oveja).

Formulario dinámico para ingresar cantidad de animales, precio por kilo/unidad y gastos mensuales.

Resultados personalizados según el animal elegido.

Botón de contacto que abre WhatsApp.

📂 Estructura del proyecto

index.html → Estructura principal de la aplicación.

style.css → Estilos modernos con fondo y botones grandes.

script.js → Lógica de login, registro y cálculos.

🛠️ Instalación

Clona este repositorio:

git clone https://github.com/TU_USUARIO/calculadora-ganadera.git

Abre la carpeta en Visual Studio Code.

Ejecuta el archivo index.html en tu navegador.

🌐 Publicación en GitHub Pages

Ve a Settings → Pages en tu repositorio.

Selecciona la rama main y carpeta /root.

Guarda y espera unos minutos.
